# TrustJob

A TrustJob é uma plataforma web para intermediação de serviços locais, conectando clientes e prestadores em um único ambiente.

O sistema permite buscar profissionais, conversar pelo chat, criar solicitações, acompanhar agendamentos, realizar check-in e checkout, gerenciar acréscimos e avaliar os serviços concluídos.

## Acesse o projeto

- Plataforma: https://trust-job.vercel.app/
- Repositório: https://github.com/henriqueRufino/TrustJob

## Funcionalidades

- Cadastro e autenticação de clientes e prestadores;
- Recuperação de senha;
- Edição de perfil e endereço;
- Busca por categorias, serviços e prestadores;
- Cadastro de serviços oferecidos pelos prestadores;
- Visualização de valores e avaliações;
- Chat em tempo real;
- Criação e aceite de solicitações;
- Controle de agendamentos;
- Check-in e checkout;
- Solicitação e aprovação de acréscimos;
- Avaliação de prestadores;
- Histórico de serviços finalizados.

## Tecnologias utilizadas

- Next.js;
- React;
- TypeScript;
- Tailwind CSS;
- Supabase;
- PostgreSQL;
- Vercel.
